Обучение с учителем


Описание: интернет-магазин «В один клик» продаёт разные товары: для детей, для дома, мелкую бытовую технику, косметику и даже продукты. Отчёт магазина за прошлый период показал, что активность покупателей начала снижаться. Привлекать новых клиентов уже не так эффективно: о магазине и так знает большая часть целевой аудитории. Возможный выход — удерживать активность постоянных клиентов. Сделать это можно с помощью персонализированных предложений.

Цель проекта: создание ML-модели, которая позволит персонализировать предложения постоянным клиентам, чтобы увеличить их покупательскую активность.

Содержание:
1. Загрузка данных
2. Предобработка данных
3. Исследовательский анализ
4. Объединение таблиц
5. Корреляционный анализ
6. Использование пайплайнов для моделей
7. Анализ важности признаков
8. Сегментация покупателей
9. Общий вывод


1. Загрузка данных

Всего содержится четыре датафрейма: market_file.csv - таблица с поведением клиента на сайте, market_money.csv - таблица с выручкой с покупателя, market_time.csv - таблица с данными о времени, проведённым на сайте, money.csv - таблица с выручкой продавца за последние три месяца. Целевой признак - покупательская активность.


2. Предобработка данных

Здесь были удалены дубликаты и преобразованы признаки.


3. Исследовательский анализ

В данном разделе были удалены аномалии в количественных признаках и провёлся осмотр категориальных


4. Объединение таблиц

Произошло объединение датафреймов с учётом разности в количествах каждого датафрейма.


5. Корреляционный анализ

Была составлена матрица корреляции и рассмотрены входные признаки на наличие связи с целевым.


6. Использование пайплайнов для моделей

Здесь был составлен пайплайн для преобразования входных признаков и обучения моделей. Некоторые категориальные признаки кодировались с помощью техники OHE, некоторые с помощью ORD. Количественные признаки были масштабированы с помощью MinMaxScaler.

Всего было выбрано четыре модели. Лучшей на кросс-валидации оказалась SVC с ядром poly, метрика ROC-AUC на кросс-валидации составила 0.91, на тестовой выборке - 0.89.


7. Анализ важности признаков

С помощью библиотеки shap удалось понять, какие именно входные признаки влияют на покупательскую активность.


8. Сегментация покупателей

Покупатели были разделены по покупательской активности и по прибыли продавца с каждого покупателя. Выяснилось, что покупатели, которые тратят больше и активность которых снизилась, перестали проявлять активность потому что на определённые товары стало меньше акций. С помощью сводных таблиц удалось понять что именно это за категории. 


9. Общий вывод

Для поставленной задачи была создана и обучена модель, анализ важности признаков которой показал наиболее частые причины падения покупательской активности. Позже было установлено, что это связано с уменьшением количества акций на определённые типы товаров. Рекомендация бизнесу - увеличить товары по акции для мелкой бытовой техники, техники для красоты и здоровья, и товаров для детей.
