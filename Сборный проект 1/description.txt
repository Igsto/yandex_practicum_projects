Сборный проект 1


Описание: интернет-магазину компьютерных игр "Стримчик" необходимо понять какие данные влияют на успешность продажи различных игр, чтобы сделать ставку на популярный продукт и спланировать рекламные кампании.

Цель проекта: составить портрет пользователя для каждого из трёх регионов и проверить гипотезы одинаковые ли средние пользовательские рейтинги платформ XOne и PC

Содержание: 
1. Загрузка данных
2. Предобработка данных
3. Исследовательский анализ данных
4. Составление портрета пользователя в каждом регионе
5. Проверка гипотез
6. Общий вывод


1. Загрузка данных

Дан один датафрейм games.csv, в нём указаны названия игр, платформа, год релиза, жанр, продажи в четырёх регионах, оценки критиков, оценки пользователей и рейтинг.


2. Предобработка данных

Были устранены дубликаты, заполнены пропуски.


3. Исследовательский анализ данных

Были визуализированы данные (гистограммы, графики, ящики с усами), удалены выбросы.


4. Составление портрета пользователя в каждом регионе

С помощью сводных таблиц удалось понять, какие платформы наиболее популярны в трёх регионах.


5. Проверка гипотез

Было проведено два t-теста для проверки некоторых гипотез. Первая гипотеза не была отвергнута, вторую пришлось отвергнуть.


6. Общий вывод

Данные были предобработаны и исследованны. На основе этих данных получилось составить портреты пользователей для некоторых регионов и проверить несколько гипотез.
